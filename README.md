## 参考与致谢

这个博客在视觉与交互上，从以下项目和作者那里学到了很多，特此致谢：

- **Anthony Fu（antfu）** —— [antfu.me](https://antfu.me)（MIT）：文章页/列表页的「降噪」美学（纯白贴底、粗标题分层、无下划线链接、深底代码块、年份描边字）。
- **isunjn** —— [serene](https://github.com/isunjn/serene)（MIT）：最初的主题基底，历经 2026-07 重构已大量重写。
- **nelsonboss** —— [nelsonboss.ink](https://nelsonboss.ink)：亮色「暖白底 + 淡网格」的质感思路。
- **clickfling** —— [blog.clickfling.top](https://blog.clickfling.top)：绿色主色 `#308251` 的配色参考。
- **Adrian Bowyer** —— 1989 年的 X11 程序 [oneko](https://en.wikipedia.org/wiki/Neko_(software))，那只追着鼠标跑的像素猫的原始作者。**特别感谢这只猫猫。**
- **adryd** —— [oneko.js](https://github.com/ZerXGIT/oneko.js)（MIT）：oneko 的网页移植版。
